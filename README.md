# CS-370
Project Overview

In this project, I developed an intelligent pirate agent using deep Q-learning to solve a pathfinding problem. The goal of the agent was to navigate through a maze and find a treasure while avoiding obstacles. The project demonstrated how reinforcement learning and neural networks can be used to help an agent learn from experience and improve its performance over time.

What Code Was Provided?

The starter code included the game environment, maze structure, and supporting classes such as TreasureMaze and GameExperience. These files provided the framework needed for the pirate agent to interact with the maze and store experiences during training.

What Code Did I Create?

My work focused on completing the Q-training algorithm. This included implementing the reinforcement learning process, balancing exploration and exploitation, storing experiences in memory, training the neural network through experience replay, tracking performance, and updating the target network during training. Through repeated training, the pirate learned successful paths to the treasure and achieved a win rate of approximately 94%.

What Do Computer Scientists Do and Why Does It Matter?

This course helped me realize that computer scientists do much more than write code. They solve problems by designing systems, developing algorithms, analyzing data, and creating solutions that improve people's lives. How Do I Approach a Problem as a Computer Scientist?

This course taught me to break large problems into smaller, manageable pieces. During this project, I had to understand how the maze worked, how the agent interacted with the environment, and how reinforcement learning could be used to improve performance. I learned the importance of testing, debugging, and making incremental improvements rather than trying to solve everything at once.

This approach reminds me of my work in education. Whether I am helping students, supporting teachers, or improving school systems, solving complex problems often requires patience, reflection, and continuous improvement.

What Are My Ethical Responsibilities to the End User and the Organization?

Computer scientists have a responsibility to create systems that are accurate, secure, fair, and trustworthy. Users depend on technology to function properly and to protect their information. Developers must consider issues such as privacy, bias, transparency, and security throughout the design process.

Because I work in education, I am especially aware of the importance of protecting student data and ensuring that technology supports human decision-making rather than replacing it. This course reinforced the idea that successful technology solutions require both technical knowledge and ethical responsibility.
